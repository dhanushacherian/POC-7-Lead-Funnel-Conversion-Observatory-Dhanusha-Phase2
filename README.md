# Lead Funnel Conversion Observatory — Phase 2

A Next.js dashboard for analyzing CRM lead-funnel conversion, stage aging, cohort performance, and funnel intelligence.

## Project Overview

This project contains the Phase 2 containerized version of the Lead Funnel Conversion Observatory.

The application provides:

- Lead funnel analysis
- KPI metrics
- Funnel visualization
- Stage aging analysis
- Cohort conversion heatmap
- Sankey flow visualization
- Filtering by available CRM dimensions
- Intelligence insights
- CSV data download
- JSON data download
- Responsive dashboard interface

## Technology Stack

- Next.js 16
- React
- TypeScript
- Tailwind CSS
- Node.js 20
- Docker
- Docker Desktop
- WSL 2
